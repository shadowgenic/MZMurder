役割

Madamis画面共通のタブバー、タブ切替、閉じる操作を管理します。

資料タブとメインタブの切り替え・閉じる処理を管理します。

実装ファイル：js/plugins/TabUI.js

プラグインパラメータ 5件

「ヘッダー初期値」はプラグインに記載された値、「デモ設定値」はこの作品の js/plugins.js に保存された値です。0や空欄は、実装側で代替値に置き換わる場合があります。

項目役割・説明型・値
メインタブの名称MainTabNameマップ画面上部に常時表示するメインタブの名前です。ヘッダー初期値: メイン（盤面）
デモ設定値: メイン（盤面）
閉じるアイコン画像CloseIconImageコンテンツタブを閉じるボタンに表示するアイコンです。型: file
参照先: img/icon/
ヘッダー初期値: close
デモ設定値: close
タブを閉じる時のSECloseSeNameタブを閉じたときに再生する効果音ファイルです。型: file
参照先: audio/se/
ヘッダー初期値: Cancel1
デモ設定値: Cancel1
閉じるSEの音量CloseSeVolumeタブを閉じたときの効果音の音量です。型: number
ヘッダー初期値: 90
デモ設定値: 90
閉じるSEのピッチCloseSePitchタブを閉じたときの効果音のピッチです。型: number
ヘッダー初期値: 100
デモ設定値: 100

プラグインコマンド 4件

01 メインタブをアクティブにする

コマンドID activateMainTab

盤面を表示するメインタブに切り替えます。

引数

引数はありません。

02 メイン以外の全タブを閉じる

コマンドID closeAllTabs

メインタブ以外の資料タブをすべて閉じます。

引数

引数はありません。

03 メインタブ固定の有効/無効

コマンドID setTabFixed

メインタブの固定状態を変更します。

引数

項目役割・説明型・値
メインタブ固定fixedメインタブを固定して閉じられない状態にするか指定します。型: boolean
ヘッダー初期値: false
