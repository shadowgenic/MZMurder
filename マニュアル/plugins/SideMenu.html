役割

情報カテゴリを画面端のスライドメニューに登録し、コンテンツタブを開きます。

資料ファイルをカテゴリへ登録します。HTMLは html/、画像資料は img/info/、アイコンは img/icon/ に配置します。

実装ファイル：js/plugins/SideMenu.js

01 情報の追加

コマンドID addInfo

資料を指定カテゴリに登録し、サイドメニューから開けるようにします。

引数

項目役割・説明型・値
カテゴリ番号category情報を追加・削除するカテゴリ番号です。型: number
範囲: 0～5
ヘッダー初期値: 0
ID (ファイル名)idHTMLまたは画像コンテンツを識別するIDです。—
表示名nameメニューに表示する情報項目の名前です。—
コンテンツ種別contentTypeHTMLは html/、画像は img/info/ から読み込みます。型: select
ヘッダー初期値: html
選択肢: HTML (html)、画像 (PNG) (image)
アイコン画像iconImageメニュー項目に表示するアイコン画像です。型: file
参照先: img/icon/
