役割

GM操作とFirebase同期に対応したスプライト式カウントダウンタイマーです。

GMがタイマーを開始・移動・停止し、状態をFirebase経由で参加者へ同期します。

実装ファイル：js/plugins/TimerEx.js

プラグインコマンド 3件

01 タイマーセット

コマンドID setTimer

秒数、表示座標、終了時SE、自動消去フラグを指定して開始します。 タイマーの終了時に終了時スイッチをONにします(自動消去フラグが立っている場合は✕で閉じたあと)。

引数

項目役割・説明型・値
秒数secondsカウントダウンする秒数です。型: number
ヘッダー初期値: 600
終了時スイッチswitchId0でスイッチ操作なし型: switch
X座標xタイマーを表示するX座標です。型: number
ヘッダー初期値: 1600
Y座標yタイマーを表示するY座標です。型: number
ヘッダー初期値: 50
終了時SE名seName0:00になったときに再生するSEファイル名（空欄で無効化）型: file
参照先: audio/se
終了時SE音量seVolume終了時に鳴らすSEの音量です。空欄で90。型: number
範囲: 0～100
ヘッダー初期値: 90
終了時SEピッチsePitch終了時に鳴らすSEのピッチです。空欄で100。型: number
範囲: 50～150
ヘッダー初期値: 100
終了時SEパンsePan終了時に鳴らすSEの定位です。空欄で0。型: number
範囲: -100～100
ヘッダー初期値: 0
終了時に自動消去autoHide0秒到達後にタイマー表示を自動で消去するか指定します。型: select
ヘッダー初期値: false
選択肢: 自動で消去する (true)、消去しない（✕ 00:00で残す） (false)
